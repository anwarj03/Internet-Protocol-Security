# Internet Protocol Security

Independent study notes and original diagrams for the nine protocols in the **Security** category of [Protocol Explorer](https://protocol-explorer-alpha.vercel.app/), designed by [Dilum Sanjaya](https://x.com/DilumSanjaya).

Start with the [protocol index](protocols/README.md), which includes a comparison table and study prompts.

## Scope

- HTTPS
- DNS over HTTPS
- DNSSEC
- WPA3
- RADIUS and IEEE 802.1X
- SSH
- TLS
- WireGuard
- IPsec

Explanations and Mermaid diagrams are independently written. Protocol notes cite primary RFCs or standards. No app screenshots or lesson text are reproduced. Visit the [interactive source](https://protocol-explorer-alpha.vercel.app/) for its animations and packet inspector.
